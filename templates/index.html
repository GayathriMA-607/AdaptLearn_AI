Learning summary

    About the system

    AdaptLearn AI

    A self-adapting AI tutor for engineering students.

    What is the project?

    AdaptLearn AI adapts what it teaches next using the learner's performance, uploaded study material, quiz results, and topic mastery.

    The system combines conversational tutoring, RAG-based study support, adaptive quizzes, and learner progress tracking.

    Problem we solve

    Engineering students need explanations, practice, revision, and help identifying weak areas. A fixed learning path does not adapt to each learner's knowledge and mistakes.

    Adaptive learning loop

    Study → Ask → Retrieve → Answer → Quiz → Evaluate → Update mastery → Adjust difficulty → Continue.

    The next practice question can now use the student's current subject and latest learning focus.

    RAG study mode

    Uploaded PDF, DOCX, and TXT material is extracted, chunked, embedded locally, and searched semantically. Relevant material is used before the open knowledge fallback.

    Open knowledge fallback

    When uploaded material does not contain a relevant answer, the tutor can use the public open-knowledge fallback rather than forcing an unrelated document chunk.

    Technology

    PythonFlaskSQLiteSentence TransformersRAGOllamaHTML/CSS/JavaScript

    What is measured?

    Quiz accuracy, correct/incorrect attempts, topic mastery, mistakes, study sessions, weak areas, and recent learning activity.

    Project goal

    Give each student a learning experience where the next activity is influenced by what they actually understand, rather than following one fixed path.
